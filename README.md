### Hi, I'm Brian, a principal mobile engineer in Boston.

I build the platforms that let teams ship across iOS, Android, visionOS, and the web: native foundations, SDKs, and the build tooling around them, so web engineers can ship real apps without becoming platform specialists. I trained as an architect, and I still work like one: systems first, craft on top.

**What I work on**
- Mobile platform architecture: Swift/SwiftUI, Kotlin/Jetpack Compose, Kotlin Multiplatform
- Native SDKs, plus the build, CI/CD, and release tooling that ships them
- Web ↔ native bridges and shared UI component platforms
- Spatial computing on visionOS
- AI in apps and in the development workflow

**Selected projects**
- [kmp-spm](https://github.com/bdiesel/kmp-spm): Kotlin + Compose Multiplatform across Android, iOS, and Wasm, delivered to Xcode as a plain Swift Package so iOS engineers never touch Gradle
- [SpaceSdk-swift](https://github.com/bdiesel/SpaceSdk-swift): a versioned Swift Package generated from a Kotlin Multiplatform SDK with Kotlin's Swift export
- [nx-shared-web-component](https://github.com/bdiesel/nx-shared-web-component): one web component, used unchanged in Angular and React
- [swift-zomekit](https://github.com/bdiesel/swift-zomekit): pure-Swift parametric geometry for architectural zome domes (iOS, macOS, visionOS, Linux)
- [ZomeBuilder](https://github.com/bdiesel/ZomeBuilder): macOS and visionOS apps for designing zome domes and exploring them in 3D
